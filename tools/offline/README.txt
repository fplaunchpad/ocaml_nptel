Functional Programming with OCaml: offline book

Extract the entire archive, then open index.html in your browser.
No server, Python, OCaml, Node.js, installation, or special browser
flags are required. Keep the assets directory alongside the HTML files.

Chapters, slides, search, runnable OCaml/OxCaml cells, quizzes, and the
Linux terminal use bundled resources. External websites, online videos,
and the analytics dashboard still need internet. Analytics retains its
existing consent settings and failed submissions are ignored offline.

Saved answers and code edits use your browser's local storage. Browser
support for persistence on local files varies; moving the extracted
folder may also make previous saved work unavailable.
